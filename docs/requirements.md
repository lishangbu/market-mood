# Market Mood · 市场情绪查看器

历史与表格：历史补录窗口滚动为最近5个已结束交易日，复盘日期列表展示全部已有记录。股票池增加完整字段表格：序号、代码、名称、涨跌幅、最新价、成交额、流通市值、总市值、换手率、封板资金、首次/最后封板时间、炸板次数、涨停统计、连板数和行业。接口日期不符的历史封炸池继续标缺失。

产品范围：个人 A 股短线看盘、复盘；参考 bankexiaopan.com 的九个模块，独立实现，不依赖参考站生产接口。

- 手机优先，深色、红涨绿跌，大字体与触控区域，底部看盘/复盘/自选。
- 九模块：昨日十亿首板、昨日十亿炸板、昨日20cm首板、昨日主板首板、昨日成交前50今日表现、八因子容量评分、今日十亿首板封炸与容量高度、主板非ST全市场封板率、沪深涨跌/阴阳/量能。
- 池明细可搜索、排序；按代码持久化自选，退出池后保留；股票详情含行情、池归属与口径，无完整K线/分时。
- 深色、红涨绿跌，正负号辅助。语音默认关闭，开启后仅承诺前台工作。
- 单进程 Web 服务；Go/net/http、SQLite、React/TypeScript，同仓库，构建网页嵌入二进制。本机用于开发，服务器目标为 Linux amd64。
- 免费源优先，页面10秒读本地缓存，自选争取10秒、全市场60秒、封炸池30–60秒。失败退避，不把HTTP成功当行情新鲜。
- 后台采集与页面无关，长期保留采集记录，不按日期自动删除；历史按日看趋势和收盘快照，断档不补零不插值。
- 开始采集前的昨日池或昨同刻数据无法验证时，显示尚未建立，不能伪造历史。
- 普通首板/炸板/封板率用沪深主板；20cm池为创业板/科创板；前50和宽度用沪深A股。排除ST、退市整理期、当日无涨跌幅限制股。
- 首板：当日涨停且上一交易日未收盘涨停。炸板：当日触及涨停且当前未封住；回封算封板，按股票去重。昨日池收盘固定。
- 昨十亿按昨收盘成交额>=10亿元，今十亿按当日累计额；高度为当前>=10亿元封板股票的最高连板数。
- 平均涨跌幅等权，停牌/缺失不参与，展示有效样本。阳线=现价>=今开。
- 放量=(今同刻/昨同刻-1)*100%；预测=今同刻/昨同刻*昨全天，缺参考数据不算。三者统一采用沪深指数接口成交额合计，与涨跌家数的个股筛选口径分离。首次启动从东方财富五日分时获取上一交易日分钟成交额，腾讯作为整组备用源；两市按共同分钟合计，昨日精确同分钟匹配，不插值、不使用附近分钟或过滤后个股成交额替代。独立采集及 SQLite 缓存，不依赖本地昨日收盘股票池；分钟金额和累计金额分别规范化，缺分钟、重复、负数、倒退或错误指数响应拒绝使用。过期或源失败时保留旧额并提示，不生成比较及预测。
- 评分v1八因子权重20/15/10/10/10/10/10/15；涨幅-3到3%、阳率20到80%、首板家数0到20、封板率30到90%线性计分并截断；任一因子缺失不算总分。为初始描述指标，未回测。

## 完成门槛
- 构建产物在无Node运行环境下独立提供页面/API/采集。
- 手机完成看情绪→池展开排序→自选→盘后趋势全流程；持久化、错误、空池、过期、断档可验证。
- 指标/适配/数据库/API/交互有针对性测试。
- 真实源取数与时间/范围检查通过。
- 完整真实交易日采集一致性验证；无法在非交易时段证明，不以模拟测试替代。
## 免费股票基础目录
- 独立 SQLite 基础库，首次启动同步、北京时间每日更新、失败保留旧目录。
- 沪深北当前A股代码/名称/交易所/板块，行业/上市日期/上市状态仅保存已核实值；无付费账号或Python依赖。
- 全量分页API及自选页名称/代码搜索、市场筛选、基础详情、加入自选。
- 免费聚合源主备切换，交易所名单核对状态可见；北交所官网不可达时不宣称已完成官网核对。
- 昨日封炸池独立重建：新浪普通日线筛选触板候选，KLC2补成交额，通达信备用；逐股缓存与完整昨日池分离。普通10%/20%价格按分位取整；检查前序交易日区分首板，连板高度不从两天行情臆造。除权窗口、上市30日内、上市日未知和ST/退市标识不按普通规则纳入。失败不能标完整，详细核对写日志；现有完整收盘池优先，历史重建不冒充全市场收盘快照。

- 数据源策略：个股报价通达信→腾讯→东方财富；历史日线通达信→新浪；指数分时腾讯→东方财富。全市场通达信因时间跨度验收未过暂为可选，默认腾讯→东方财富，不放宽180秒验证；同花顺默认不启用。来源设置支持tdx，已有配置不随默认值变更自动迁移。代码需在数据边界处详细注释单位、来源时间、失败/回退和当前快照字段契约；模块阅读说明见 data-sources.md。
